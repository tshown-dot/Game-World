Equation Valley · Lesson 4-9 · Use Patterns to Write and Solve Equations
1. THE MACHINE

A stone goes in with a number on it. The machine changes it by a rule, and a new stone flies out.

c = 8b : in 5, out 40

2. CATCH, SET, FEED

Catch: put the basket where the output will land. Set the dials to the rule a table shows. Feed the machine your own stones to work out a hidden rule.

3. STAKES

Every mistake HEATS the machine. When it overheats, a torch goes out. Lose all 3 torches and the machine seals shut. Crack the Ancient Runes to win!
